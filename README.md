# 声场 · SOUNDFIELD

一个只在本机运行的本地音乐播放器。它会自动扫描本文件夹（包含子文件夹）里的音频文件，把歌曲列进播放队列；音频文件始终留在本机，不会上传到任何服务器。

## 开始使用

1. 安装 Python 3.10 或更高版本。
2. 在本目录打开命令行，安装依赖：
   ```bat
   py -3 -m pip install -r requirements.txt
   ```
3. 双击 **`启动播放器.cmd`**（或在本目录执行 `py -3 app.py`）。
4. 命令行窗口会显示播放地址（默认 `http://127.0.0.1:8765/`），浏览器通常会自动打开。
5. 把歌曲放进本目录或其子文件夹，播放器会自动扫描。

播放器窗口需要保持打开。关闭它或按 `Ctrl + C` 就会停止服务。

## 手机 / 平板访问

默认的「启动播放器」只监听本机，手机是访问不到的。需要用手机访问时：

1. 确保电脑和手机连接**同一个 Wi-Fi**。
2. 双击 **`启动手机访问.cmd`**（不是普通的启动播放器）。
3. Windows 防火墙询问时，允许 Python 访问**专用网络**。
4. 黑色窗口会显示一行 `手机访问 http://10.x.x.x:8765/`。
5. 在手机浏览器里打开这个地址，然后可以把它「添加到主屏幕」当播放器用。

电脑上的音乐文件不会复制到手机，手机会通过局域网直接播放电脑上的歌曲。电脑和这个窗口需要保持开启。

> 这个模式下同一 Wi-Fi 里的其他人也可能打开你的播放器。只在可信的家庭网络中启用，用完关闭窗口；不要在公共 Wi-Fi 或直接暴露到公网。

如果手机打不开，依次检查：手机和电脑是否在同一网段、防火墙是否允许 Python、路由器是否开启了“访客网络隔离”，以及窗口里显示的 IP 是否输错。

### 不在同一网络（例如在公司连家里的电脑）

可以使用 [Tailscale](https://tailscale.com/)：电脑和手机登录同一个 Tailscale 账号，运行 `启动手机访问.cmd`，然后在手机访问 `http://<电脑的 Tailscale IP>:8765/`。这比直接做公网端口映射安全。

### 手机上的限制

- 播放、歌单、搜索、收藏、歌词和返回操作都可以用。
- 「补齐歌词」依赖桌面 Chrome/Edge 的文件夹授权，手机浏览器通常不支持；手机可以正常显示电脑上已有的 `.lrc` 和在线歌词。
- 手机端不能直接扫描手机里的音乐文件；曲库仍然来自电脑上的本目录。

## 双击没反应怎么办

1. 重新双击 `启动播放器.cmd`，它会在出错时保留窗口并显示原因。
2. 如果提示找不到 Python/Flask，先执行：
   ```bat
   py -3 -m pip install -r requirements.txt
   ```
3. 如果浏览器没有自动打开，但命令行显示 `Running on http://127.0.0.1:8765`，直接在浏览器地址栏输入这个地址。

## 添加歌曲

把 `.mp3`、`.m4a`、`.flac`、`.wav`、`.ogg`、`.opus`、`.aac` 等音频文件直接放进这个文件夹，或者放进它的子文件夹：

- 播放器每 20 秒自动同步一次曲库；
- 也可以点左侧的 **重新扫描** 立即刷新；
- 点 **打开文件夹** 可以直接在资源管理器中查看曲库目录。

歌曲信息优先读取文件内嵌标签；没有标签时，会从文件名推断。例如：

`孙燕姿《我不难过》百万豪装录音棚大声听 - JLRS-LeoFM.m4a`

会显示为：歌手「孙燕姿」、歌名「我不难过」、专辑「百万豪装录音棚大声听」、来源「JLRS-LeoFM」。没有内嵌封面的歌曲会自动生成一张和歌名、歌手呼应的封面。

## 歌单：按文件夹自动分组

在曲库目录里新建一个文件夹，把某个歌手的歌放进去，这个文件夹就会自动变成左侧的一个歌单。

```text
音乐播放器/
├─ 周杰伦歌单/
│  ├─ 周杰伦 - 一路向北.mp3
│  ├─ 周杰伦 - 晴天.mp3
│  └─ 叶惠美/以父之名.mp3
├─ 孙燕姿歌单/
│  └─ 孙燕姿《我不难过》....m4a
└─ 其他歌曲.mp3
```

- 文件夹名就是歌单名，例如 `周杰伦歌单`。
- 歌单里的子文件夹（如按专辑分的文件夹）也会归入这个歌单。
- 点左侧歌单，只显示这个文件夹里的歌曲；在歌单里点「播放全部」、上一首/下一首、随机和循环，都只在这个歌单范围内。
- 以后再添加 `林俊杰歌单`、`陈奕迅歌单` 等文件夹，播放器会在 20 秒内自动识别，也可以点「重新扫描」。
- 空文件夹不会显示；删除或重命名文件夹后，左侧歌单会自动更新。
- 根目录下的单曲仍然可以在「全部歌曲」里找到。

## 歌曲播放页与歌词

点击任意一首歌会进入沉浸播放页：

- 左上角 **返回** 键回到刚才的歌单/全部歌曲界面，滚动位置和播放状态都会保留。
- 歌词会随播放时间自动高亮、自动滚动；点击任意一句歌词可以直接跳到那一句。
- 播放页底部可以播放/暂停、上一首/下一首、拖动进度条；`Esc` 也可以返回。

歌词按以下顺序查找：

1. 歌曲旁边的同名 `.lrc` 文件，例如 `周杰伦歌单/周杰伦 - 一路向北.lrc`；
2. 音频文件内嵌的歌词（MP3 USLT、M4A `©lyr`、FLAC `LYRICS` 等）；
3. 本地没有时，会把**歌名和歌手**发送到 [LRCLIB](https://lrclib.net/) 在线匹配。不会发送音频文件。
4. 如果网络不可用，会显示「暂无歌词」；可以点「重新匹配歌词」重试，或把同名 `.lrc` 放进歌曲文件夹。

> 这是**按歌名/歌手匹配现成歌词**，不是从音频里听写歌词。音乐带伴奏和混响，自动语音识别很容易出错，所以没有采用听写方案。

支持带时间轴的 LRC（`[00:12.34]歌词`）；只有纯文本歌词时，会按歌曲时长自动估算时间轴并滚动。`[offset:...]` 标签也会生效。

### 批量补齐歌词

播放队列右上角有 **「补齐歌词」** 按钮：

1. 点它，在系统窗口中选择音乐播放器根目录（包含 `周杰伦歌单`、`孙燕姿歌单` 的那一层）。
2. 播放器会逐首在线匹配歌词，并自动写成同名 `.lrc` 放到歌曲旁边。
3. 已经有 `.lrc` 的歌曲会跳过，不会覆盖。
4. 按钮会显示进度（例如 `3/20`），完成后提示保存、跳过、未找到各多少首。

这个功能使用浏览器的 File System Access API，推荐 Chrome / Edge；歌词直接写入你选择的本地文件夹。匹配不到的歌需要手动放 `.lrc`，或稍后重试。

> 歌词是可选功能。不想使用在线匹配时，断网或只使用本地 `.lrc` 即可，播放器本身不受影响。

## 播放器功能

- 播放 / 暂停、上一首 / 下一首、拖动音频波形跳转
- 点击歌曲进入沉浸播放页，歌词自动高亮滚动，左上角返回
- 随机播放、列表循环、单曲循环
- 收藏歌曲（保存在浏览器本地）
- 按文件夹自动生成歌单，歌单内独立播放队列
- 搜索歌曲、歌手、专辑（歌单内搜索只查当前歌单）
- 音量、静音、0.75× / 1× / 1.25× / 1.5× 倍速
- 实时频谱、曲目波形、系统媒体控制（Media Session）
- 支持用键盘操作

### 键盘快捷键

| 操作 | 按键 |
| --- | --- |
| 播放 / 暂停 | `Space` |
| 后退 / 快进 5 秒 | `←` / `→` |
| 音量增减 | `↑` / `↓` |
| 上一首 / 下一首 | `P` / `N` |
| 静音 | `M` |
| 随机播放 | `S` |
| 循环模式 | `R` |
| 收藏当前歌曲 | `F` |
| 搜索 | `/` |
| 关闭弹窗 | `Esc` |

## 运行环境

- Windows 10 / 11
- Python 3.10 或更高版本
- Flask（执行 `pip install -r requirements.txt`）

如果双击 bat 没有反应，可以在本文件夹打开命令行，执行：

```bat
python app.py
```

启动后控制台会显示实际访问地址（默认是 `http://127.0.0.1:8765/`）。如果 8765 端口被占用，会自动顺延到下一个空闲端口。

## 文件说明

```text
app.py             本地音乐服务：扫描曲库、读取标签、提供音频流
web/index.html     播放器界面
web/styles.css     界面样式
web/app.js         播放器交互
启动播放器.cmd      Windows 本机启动
启动手机访问.cmd    同一 Wi-Fi 下手机访问
启动播放器.bat      Windows 双击启动（备用）
requirements.txt   Python 依赖
```

本仓库只包含程序代码，不包含音频文件、歌词文件或带专辑封面的截图；这些内容由 `.gitignore` 排除。

## 说明

- 播放器只监听 `127.0.0.1`，局域网里的其他设备无法访问。
- 浏览器能播放的格式取决于浏览器本身。M4A、MP3、FLAC、WAV、OGG 在现代 Chrome / Edge 中通常可直接播放；APE、DSF 等格式可能需要先转换成 FLAC / WAV。
- 音频通过支持 HTTP Range 的本地接口传输，可以随意拖动进度条。
- 在线歌词匹配只会把歌名和歌手发送到 LRCLIB，不会上传音频；本地有 `.lrc` 或内嵌歌词时不会联网。
