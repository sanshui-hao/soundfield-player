# 声场 · SOUNDFIELD

一个本地音乐播放器：自动扫描本文件夹（含子文件夹）里的音频，把歌曲列进播放队列。音频始终留在电脑上，不会上传到任何服务器。

默认只在本机使用；双击 **`启动远程访问.cmd`** 之后，手机会拿到一个公网 `https://` 地址，**不用连同一个 Wi-Fi，用移动数据也能听**。电脑和那个黑色窗口需要保持开启。

> 手机端每天怎么点、怎么添加到桌面，看这份更短的 **[手机使用说明](手机使用说明.md)**。

## 开始使用（电脑本机）

1. 安装 Python 3.10 或更高版本。
2. 在本目录打开命令行，安装依赖：
   ```bat
   py -3 -m pip install -r requirements.txt
   ```
3. 双击 **`启动播放器.cmd`**（或在本目录执行 `py -3 app.py`）。
4. 命令行会显示播放地址（默认 `http://127.0.0.1:8765/`），浏览器通常会自动打开。
5. 把歌曲放进本目录或其子文件夹，播放器会自动扫描。

播放器窗口需要保持打开。关闭它或按 `Ctrl + C` 就会停止服务。

## 手机远程访问（不在同一网络）

这是给「人在外面、电脑在家里开着」准备的模式。手机用 4G/5G 或任何 Wi-Fi 都能访问，不需要路由器端口映射，也不需要改防火墙。

### 第一次使用

1. 在电脑上双击 **`启动远程访问.cmd`**（不是普通的「启动播放器」）。
2. 等黑色窗口出现下面三行（第一次大约需要 10–60 秒；如果本机还没有隧道组件，会先下载约 55 MB，可能要几分钟）：
   ```text
   手机地址   https://xxxx-xxxx-xxxx.trycloudflare.com
   访问码     123456
   ```
   同时浏览器会自动打开一个二维码页面（`tools/remote-access.html`）。
3. 用手机相机扫二维码，或把链接发到手机上打开（微信、备忘录、短信都可以）。
4. 扫码会自动登录；如果是手动打开链接，输入窗口里显示的 **访问码**。
5. 登录后，在手机浏览器菜单里点 **「添加到主屏幕」**：
   - iPhone Safari：分享按钮 → 添加到主屏幕；
   - Android Chrome：右上角菜单 → 添加到主屏幕 / 安装应用。
   以后点手机桌面上的「声场」图标就能直接听。

### 以后每天怎么用

1. 电脑开机，双击 **`启动远程访问.cmd`**，黑色窗口保持开启。
2. 手机点桌面上的「声场」图标。如果电脑刚重启过，地址会变，重新扫一次二维码即可。
3. 播放、歌单、搜索、收藏、歌词、进度拖动都和电脑上一样；手机只是遥控和播放，歌曲仍然从电脑读取。

只要窗口不关，链接就一直有效。关闭窗口、电脑睡眠或关机，远程访问都会停止。

### 重要说明

- **电脑不能睡眠。** 远程访问启动器会阻止「自动睡眠」，屏幕仍然可以关闭；但合上笔记本盖子、手动点睡眠、断电都会让服务停止。建议在「设置 → 系统 → 电源」里把插电时的睡眠设为「从不」。
- **地址会变。** `trycloudflare.com` 的免费快速隧道每次启动都会分配新地址。电脑重启后重新扫码即可，不需要重新配置。
- **手机流量。** 歌曲是从电脑实时传到手机的，会消耗手机流量：MP3 大约 60–150 MB/小时，无损 FLAC 更高。用 Wi-Fi 时则走 Wi-Fi。
- **不要把这个窗口留在公共电脑上。** 链接加访问码就是进入你曲库的钥匙。

### 安全与隐私

- 公网地址带访问码保护：没登录的人只能看到「输入访问码」页面，接口和音频都会返回 401。
- 访问码保存在本机 `.remote-access.json`，登录状态在手机上保留 180 天；换手机或清除浏览器数据后重新输入一次即可。
- 想换访问码：关闭窗口，编辑 `.remote-access.json` 里的 `"code"`（至少 4 位），再启动。想让所有手机立刻退出登录，把同一文件的 `"secret"` 也改掉。
- 远程模式只监听 `127.0.0.1`，所以同一 Wi-Fi 里的其他人**不能**通过局域网 IP 访问；公网流量经由 Cloudflare 的 HTTPS 隧道转发，不需要在路由器上开端口。
- 音频文件不会上传到任何服务器；但公网链路由 Cloudflare 转发（TLS 加密），Cloudflare 能看到经过的流量。介意的话请只在可信网络使用，或改用下面的 Tailscale 私有方案。
- 「打开文件夹」是电脑本地功能，手机端会返回 403；「补齐歌词」依赖桌面 Chrome/Edge 的文件夹授权，手机浏览器通常不支持。

### 手机打不开怎么办

1. 黑色窗口还在吗？关了窗口远程访问就停了。
2. 刚启动的链接，Cloudflare 的新域名可能要用 10–30 秒才生效，等一会儿再扫；最多等 1–2 分钟。
3. 切换一下手机网络：Wi-Fi 打不开就换移动数据，移动数据打不开就换 Wi-Fi。部分校园网/公司网对 `trycloudflare.com` 的 DNS 解析较慢。
4. 确认访问码输入正确；扫码链接通常会自动登录。
5. 仍然不行时，在电脑上重新启动一次 `启动远程访问.cmd`，用新生成的二维码再试。

### 想要固定地址？

如果不想每次重启都换链接，可以用 [Tailscale](https://tailscale.com/) 做私有网络：

1. 电脑和手机都安装 Tailscale，登录同一个账号。
2. 电脑上双击 **`启动手机访问.cmd`**（局域网模式）。
3. 手机在任何网络下访问 `http://<电脑的 Tailscale IP>:8765/`。

这个地址不会变，而且只有你自己 Tailscale 网络里的设备能访问，不经过公网。代价是手机需要安装 Tailscale 并登录；它需要账号，不能像上面的快速隧道那样零配置。

## 同一 Wi-Fi 访问（可选，速度更快）

如果手机和电脑在同一个 Wi-Fi，用这个模式延迟更低，也不消耗公网流量：

1. 双击 **`启动手机访问.cmd`**（不是普通的启动播放器）。
2. Windows 防火墙询问时，允许 Python 访问**专用网络**。
3. 黑色窗口会显示一行 `手机访问 http://10.x.x.x:8765/`。
4. 在手机浏览器里打开这个地址，然后添加到主屏幕。

这个模式没有访问码，同一 Wi-Fi 里的其他人也可能打开你的播放器。只在可信的家庭网络中启用，用完关闭窗口；不要在公共 Wi-Fi 使用。

## 手机上的限制

- 播放、歌单、搜索、收藏、歌词和返回操作都可以用。
- 「补齐歌词」依赖桌面 Chrome/Edge 的文件夹授权，手机浏览器通常不支持；手机上可以正常显示电脑上已有的 `.lrc` 和在线歌词。
- 手机端不能直接扫描手机里的音乐文件；曲库仍然来自电脑上的本目录。
- 浏览器能播放的格式取决于浏览器本身。M4A、MP3、FLAC、WAV、OGG 在现代 Chrome / Edge / Safari 中通常可直接播放；APE、DSF 等格式可能需要先转换成 FLAC / WAV。

## 双击没反应怎么办

1. 重新双击 `启动播放器.cmd` 或 `启动远程访问.cmd`，它会在出错时保留窗口并显示原因。
2. 如果提示找不到 Python/Flask，先执行：
   ```bat
   py -3 -m pip install -r requirements.txt
   ```
3. 如果浏览器没有自动打开，但命令行显示 `Running on http://127.0.0.1:8765`，直接在浏览器地址栏输入这个地址。
4. 远程模式第一次启动时会准备 Cloudflare 隧道组件（约 55 MB）。如果下载很慢，可以手动下载
   [cloudflared-windows-amd64.exe](https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe)，
   改名为 `cloudflared.exe` 放进 `tools` 文件夹。

## 添加歌曲

把 `.mp3`、`.m4a`、`.flac`、`.wav`、`.ogg`、`.opus`、`.aac` 等音频文件直接放进这个文件夹，或者放进它的子文件夹：

- 播放器每 20 秒自动同步一次曲库；
- 也可以点左侧的 **重新扫描** 立即刷新；
- 点 **打开文件夹** 可以直接在资源管理器中查看曲库目录（仅电脑端）。

歌曲信息优先读取文件内嵌标签；没有标签时，会从文件名推断。例如：

`孙燕姿《我不难过》百万豪装录音棚大声听 - JLRS-LeoFM.m4a`

会显示为：歌手「孙燕姿」、歌名「我不难过」、专辑「百万豪装录音棚大声听」、来源「JLRS-LeoFM」。没有内嵌封面的歌曲会自动生成一张和歌名、歌手呼应的封面。

## 歌单：按文件夹自动分组

在曲库目录里新建一个文件夹，把某个歌手的歌放进去，这个文件夹就会自动变成左侧的一个歌单。

```text
音乐播放器/
├─ 周杰伦歌单/
│  ├─ 周杰伦 - 一路向北.mp3
│  ├─ 周杰伦 - 晴天.mp3
│  └─ 叶惠美/以父之名.mp3
├─ 孙燕姿歌单/
│  └─ 孙燕姿《我不难过》....m4a
└─ 其他歌曲.mp3
```

- 文件夹名就是歌单名，例如 `周杰伦歌单`。
- 歌单里的子文件夹（如按专辑分的文件夹）也会归入这个歌单。
- 点左侧歌单，只显示这个文件夹里的歌曲；在歌单里点「播放全部」、上一首/下一首、随机和循环，都只在这个歌单范围内。
- 以后再添加 `林俊杰歌单`、`陈奕迅歌单` 等文件夹，播放器会在 20 秒内自动识别，也可以点「重新扫描」。
- 空文件夹不会显示；删除或重命名文件夹后，左侧歌单会自动更新。
- 根目录下的单曲仍然可以在「全部歌曲」里找到。

## 歌曲播放页与歌词

点击任意一首歌会进入沉浸播放页：

- 左上角 **返回** 键回到刚才的歌单/全部歌曲界面，滚动位置和播放状态都会保留。
- 歌词会随播放时间自动高亮、自动滚动；点击任意一句歌词可以直接跳到那一句。
- 播放页底部可以播放/暂停、上一首/下一首、拖动进度条；`Esc` 也可以返回。

歌词按以下顺序查找：

1. 歌曲旁边的同名 `.lrc` 文件，例如 `周杰伦歌单/周杰伦 - 一路向北.lrc`；
2. 音频文件内嵌的歌词（MP3 USLT、M4A `©lyr`、FLAC `LYRICS` 等）；
3. 本地没有时，会把**歌名和歌手**发送到 [LRCLIB](https://lrclib.net/) 在线匹配。不会发送音频文件。
4. 如果网络不可用，会显示「暂无歌词」；可以点「重新匹配歌词」重试，或把同名 `.lrc` 放进歌曲文件夹。

> 这是**按歌名/歌手匹配现成歌词**，不是从音频里听写歌词。音乐带伴奏和混响，自动语音识别很容易出错，所以没有采用听写方案。

支持带时间轴的 LRC（`[00:12.34]歌词`）；只有纯文本歌词时，会按歌曲时长自动估算时间轴并滚动。`[offset:...]` 标签也会生效。

### 批量补齐歌词

播放队列右上角有 **「补齐歌词」** 按钮：

1. 点它，在系统窗口中选择音乐播放器根目录（包含 `周杰伦歌单`、`孙燕姿歌单` 的那一层）。
2. 播放器会逐首在线匹配歌词，并自动写成同名 `.lrc` 放到歌曲旁边。
3. 已经有 `.lrc` 的歌曲会跳过，不会覆盖。
4. 按钮会显示进度（例如 `3/20`），完成后提示保存、跳过、未找到各多少首。

这个功能使用浏览器的 File System Access API，推荐 Chrome / Edge；歌词直接写入你选择的本地文件夹。匹配不到的歌需要手动放 `.lrc`，或稍后重试。

> 歌词是可选功能。不想使用在线匹配时，断网或只使用本地 `.lrc` 即可，播放器本身不受影响。

## 播放器功能

- 播放 / 暂停、上一首 / 下一首、拖动音频波形跳转
- 点击歌曲进入沉浸播放页，歌词自动高亮滚动，左上角返回
- 随机播放、列表循环、单曲循环
- 收藏歌曲（保存在浏览器本地）
- 按文件夹自动生成歌单，歌单内独立播放队列
- 搜索歌曲、歌手、专辑（歌单内搜索只查当前歌单）
- 音量、静音、0.75× / 1× / 1.25× / 1.5× 倍速
- 实时频谱、曲目波形、系统媒体控制（Media Session）
- 支持用键盘操作

### 键盘快捷键

| 操作 | 按键 |
| --- | --- |
| 播放 / 暂停 | `Space` |
| 后退 / 快进 5 秒 | `←` / `→` |
| 音量增减 | `↑` / `↓` |
| 上一首 / 下一首 | `P` / `N` |
| 静音 | `M` |
| 随机播放 | `S` |
| 循环模式 | `R` |
| 收藏当前歌曲 | `F` |
| 搜索 | `/` |
| 关闭弹窗 | `Esc` |

## 运行环境

- Windows 10 / 11
- Python 3.10 或更高版本
- Flask（执行 `pip install -r requirements.txt`）

远程访问额外需要 `tools/cloudflared.exe`（启动器会自动下载；本机已有则直接使用）和 `tools/vendor/segno`（生成二维码，已附带）。不需要 Node.js，不需要路由器端口映射。

如果双击 bat 没有反应，可以在本文件夹打开命令行，执行：

```bat
python app.py
```

启动后控制台会显示实际访问地址（默认是 `http://127.0.0.1:8765/`）。如果 8765 端口被占用，会自动顺延到下一个空闲端口。

```text
app.py                 本地音乐服务：扫描曲库、读取标签、提供音频流、访问码保护
remote.py              远程访问启动器：启动播放器 + Cloudflare 隧道 + 二维码状态页
web/index.html         播放器界面
web/styles.css         界面样式
web/app.js             播放器交互
web/login.html         手机首次访问时的访问码页面
web/manifest.webmanifest  PWA / 添加到主屏幕
web/icon-*.png         桌面图标
启动播放器.cmd           Windows 本机启动
启动手机访问.cmd         同一 Wi-Fi 下手机访问
启动远程访问.cmd         不在同一网络时，手机通过公网访问
启动播放器.bat           Windows 双击启动（备用）
tools/cloudflared.exe   Cloudflare 隧道组件（首次使用自动下载，不进入仓库）

```

`.remote-access.json` 保存访问码和会话密钥，`tools/remote-access.html` 是二维码页面，`tools/*.log` 是运行日志；这些文件都只在本机，已被 `.gitignore` 排除。不要把它们发到公开的地方。

本仓库只包含程序代码，不包含音频文件、歌词文件或带专辑封面的截图；这些内容由 `.gitignore` 排除。

## 说明

- 默认启动只监听 `127.0.0.1`，局域网里的其他设备无法访问。
- 远程模式也只监听 `127.0.0.1`，由 Cloudflare 隧道对外提供 HTTPS 地址；手机访问需要访问码。
- 浏览器能播放的格式取决于浏览器本身。M4A、MP3、FLAC、WAV、OGG 在现代 Chrome / Edge / Safari 中通常可直接播放；APE、DSF 等格式可能需要先转换成 FLAC / WAV。
- 音频通过支持 HTTP Range 的本地接口传输，可以随意拖动进度条。
- 在线歌词匹配只会把歌名和歌手发送到 LRCLIB，不会上传音频；本地有 `.lrc` 或内嵌歌词时不会联网。
- Cloudflare 的免费快速隧道没有可用性保证，适合个人自用；如果链接断开，启动器会自动重连并生成新地址。
